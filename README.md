# fairgreen-pharmacy-ai

AI-powered pharmacy call management system MVP with:
- Node.js + Express backend APIs
- Twilio voice webhook handling
- OpenAI-assisted query classification/response with fallback logic
- Transcript, prescription, and callback queue management
- React + Tailwind admin dashboard

## Quick Start

```bash
cd backend && npm install && npm test && npm start
cd frontend && npm install && npm run dev
```
